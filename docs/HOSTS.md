### 2. Override Hosts Settings

> **Warning:** This only works for you when open the web and routing to different website.

If the VPN and DNS doesn't work for you, Add this into your hosts file.

```bash
104.21.234.102  gelbooru.com
104.27.207.92   nhentai.net
185.23.214.98   i.nhentai.net

```

Or, if this doesn't work for you or extra laggy, check the [IP Tracker](https://www.ip-tracker.org/), replace the address based from your ip tracker. Remember before you do this, backup your hosts file.

#### Location hosts file based on your system : 
- Windows : C:/Windows/System32/drivers/etc/hosts
- Linux   : /etc/hosts
- Mac     : /private/etc/hosts
